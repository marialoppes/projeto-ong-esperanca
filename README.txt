PROJETO ONG ESPERANÇA
=====================

Sobre o projeto
---------------
Site desenvolvido como atividade acadêmica para a ONG Esperança.
O projeto apresenta a organização, divulga seus projetos e permite
que visitantes preencham um formulário de cadastro.

Estrutura de arquivos
---------------------
projeto_ong/
├── css/
│   └── style.css
├── html/
│   ├── index.html
│   ├── projetos.html
│   └── cadastro.html
├── img/
│   ├── logo_ong.png
│   ├── doacoes_ong.png
│   └── voluntarios_ong.png
├── js/
│   ├── router.js
│   ├── storage.js
│   └── validacao.js
└── README.txt

Tecnologias
-----------
- HTML5: estrutura e conteúdo das páginas.
- CSS3: estilos, organização visual e responsividade.
- JavaScript: navegação, validação e armazenamento dos dados
  do formulário no navegador.

Como executar
-------------
1. Abra a pasta do projeto no Visual Studio Code.
2. Abra a página html/index.html.
3. Inicie a página usando a extensão Live Server.
4. O site será aberto no navegador.

Observação: executar pelo Live Server ajuda a carregar corretamente
os arquivos JavaScript organizados em módulos.
